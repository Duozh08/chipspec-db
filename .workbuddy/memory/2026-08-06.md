# 2026-08-06 工作日志

## ChipSpec DB 数据合并与数量核对

### 需求背景
用户对比 Excel（芯片.xlsx 120 行移动CPU / 游戏本.xlsx 619 行）与网站数量，发现对不上；并反馈游戏本同型号多配置未合并、卡片年份重复。

### 核对结论
- **芯片**：Excel 120 颗移动 CPU **全部已在网站（0 缺失）**；网站移动端显示 126 = 120 CPU + 6 颗手动收录移动 GPU（Excel 无 GPU 列）→ 数量差异是 GPU 造成，非缺失
- **游戏本**：原按 (品牌,中文名称,型号) 分组 → 378 个，其中 33 组因名称变体（"拯救者 Y9000P"/"拯救者Y9000P 2024"、天选酷睿版/锐龙版、"AI元启"等）被错误拆分

### 修复
- `scripts/gen-data.py` 分组逻辑改为 **(品牌, 规范化名称, 型号)**：`norm_name()` = 去空格 + 去末尾年份 + 去 AI元启/酷睿版/锐龙版
- 重新生成：**378 → 345 款**（合并 33 组），0 重复 id；release 取组内最早发布时间
- **年份去重**：卡片标题 `formatCardTitle` 与详情页标题增加防御——displayName 已含年份则不再追加"-YYYY款"
- 首页 FEATURED_LAPTOPS 的 6 个 id 因规范化全部变化，已更新为新 id（如 lenovo-y9000p-16irx9、dell-alienwarem18r2-m18-r2）
- 注意：规范化后 id 不再含年份（"lenovo-y9000p-16irx9"），硬编码 id 引用需重新核对

### 技术要点
- 同型号跨多个规范名（联想 16IRX9 → 拯救者Y7000P/Y9000P/Y9000K 三组）是**不同产品共用型号**，必须按规范名分开，不能按 (品牌,型号) 一刀切合并（那样会误合并成 294 组）
